      Metodologia

      Como funciona

      Uma régua única para todos. A cada poucos minutos o Radar VI procura projetos novos no GitHub, confere cada um na branch principal (estrelas, commits, README) e uma IA lê o que o projeto publica para dizer em que marco ele está. Tudo automático; nada é escrito à mão.
