                  Como estes números são medidosHow these numbers are measuredCómo se miden estos números

                  Um script local (coletar.py) lê a API do GitHub, o histórico de commits da branch main e o texto das issues de coordenação: #7154 (roadmap e escada do boot) e #313 (camada D3D12). Essas issues são escritas à mão pelos coordenadores, então o painel mostra o que eles registraram naquele momento. A porcentagem é a média de 4 contagens que o próprio projeto publica (detalhes no Resumo). Os textos copiados das issues e do README são traduzidos automaticamente com o Argos Translate, de código aberto, que roda de graça no próprio GitHub Actions; a tradução pode ter erros. Visual inspirado em Vice City à noite, sem nenhuma arte ou marca do jogo.

                  A local script (coletar.py) reads the GitHub API, the commit history of the main branch and the text of the coordination issues: #7154 (boot roadmap and ladder) and #313 (D3D12 layer). The coordinators write those issues by hand, so the dashboard shows what they had recorded at that moment. The percentage is this dashboard's own estimate, not the project's. Look inspired by Vice City at night, with no art or branding from the game.

                  Un script local (coletar.py) lee la API de GitHub, el historial de commits de la rama main y el texto de las issues de coordinación: #7154 (hoja de ruta y escalera del arranque) y #313 (capa D3D12). Los coordinadores escriben esas issues a mano, así que el panel muestra lo que habían registrado en ese momento. El porcentaje es la media de 4 recuentos que el propio proyecto publica (detalles en el Resumen). Los textos copiados de las issues y del README se traducen automáticamente con Argos Translate, de código abierto, que corre gratis en el propio GitHub Actions; la traducción puede tener errores.
